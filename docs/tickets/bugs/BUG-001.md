# BUG-001: sync.sh fails to run — wrong regex escape in parse_stack

Status: Open
Priority: Low
Created: 2026-07-23 20:00
Steps to Reproduce: Run `bash sync.sh` from the repo root after docs/SRS.md has a "## Tech Stack" table.

Issue: In the `parse_stack` function, the pattern `grep -v '^\|---'` is meant to exclude markdown table separator lines (`|---|---|`), but because `\|` in GNU grep basic regex is the alternation operator (not a literal pipe), the pattern matches ALL lines (`^` OR `---`). As a result every line is filtered out, `grep -v` exits 1 (no output), and because `set -euo pipefail` is active, the whole script stops there, so the stack section of CLAUDE.md is never updated automatically.

Expected: `sync.sh` successfully parses the Tech Stack table from SRS.md and updates the `<!-- STACK_START -->...<!-- STACK_END -->` section in `.claude/CLAUDE.md` without errors.

Suggested fix: replace `'^\|---'` with its literal version: just use `'^\|'` without the backslash to match a literal leading pipe in BRE (`grep -v '^|---'`), or use `grep -vE '^\|---'` (ERE) if you want to keep the backslash style.
